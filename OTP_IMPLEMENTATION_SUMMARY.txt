SÉCURITÉ — IMPLÉMENTÉE
═══════════════════════════════════════════════════════════════════════════════

✅ Stockage:
   • Codes JAMAIS en clair
   • password_hash() pour stockage
   • password_verify() pour vérification

✅ Génération:
   • random_int(100000, 999999) côté serveur
   • Jamais en URL, jamais en session clair
   • Jamais généré côté JavaScript

✅ Transmission:
   • Email avec PHPMailer
   • HTTPS pour formulaires
   • CSRF tokens obligatoires

✅ Protection:
   • Max 5 tentatives (puis OTP invalide)
   • Rate limit: 1 OTP/60s, max 3/heure
   • Message générique: "Code invalide ou expiré"
   • Expiration: 5 minutes

✅ Logging:
   • Code JAMAIS loggué
   • Seulement: user_id + purpose
   • Production: ERROR level uniquement

QUICK START (5 MINUTES)
═══════════════════════════════════════════════════════════════════════════════

1. Setup:
   php security/setup_otp.php

2. Test:
   php security/test_otp.php

3. Config .env:
   MAIL_FROM_ADDRESS=noreply@coiffeschez-toi.local
   MAIL_FROM_NAME=Coiffe Chez Toi

4. Utiliser dans inscription.php (exemple):
   
   require_once 'src/Services/OtpService.php';
   require_once 'src/Services/EmailService.php';
   
   $otp_service = new OtpService($pdo);
   $result = $otp_service->generate($user_id, 'registration');
   
   if ($result['success']) {
       $email_service = new EmailService();
       $email_service->sendOtpCode(
           $user_email,
           $result['code'],
           5,
           'registration'
       );
       
       $otp_purpose = 'registration';
       include 'views/components/otp_verification.php';
   }

ARCHITECTURE FINALE
═══════════════════════════════════════════════════════════════════════════════

otp_codes (table)
    ├── code_hash       (password_hash du code 6 chiffres)
    ├── expires_at      (NOW() + 5 minutes)
    ├── attempts        (max 5)
    ├── purpose         (registration, password_reset, ...)
    └── used_at         (NULL jusqu'à utilisation)

OtpService (classe)
    ├── generate()      (crée code, le hash, le stocke)
    ├── verify()        (vérifie contre hash, gère tentatives)
    ├── canRequest()    (rate limit check)
    └── invalidate()    (marque comme utilisé)

EmailService (classe)
    ├── sendOtpCode()   (envoie le code à l'utilisateur)
    └── sendNotification() (envoie emails génériques)

otp_verification.php (composant)
    ├── 6 champs numériques
    ├── Compte à rebours
    ├── Gestion clavier (Backspace, collage)
    └── Bouton renvoyer

verify_otp.php (gestionnaire)
    ├── Traite POST
    ├── Appelle OtpService::verify()
    └── Mets à jour session
