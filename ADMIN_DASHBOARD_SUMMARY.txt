                         TOP 4 COIFFEURS — NOTATION
================================================================================

SYSTÈME DE CLASSEMENT
─────────────────────────────────────────────────────────────────────────────

Critère principal : NOMBRE DE RENDEZ-VOUS COMPLÉTÉS

Requête SQL :
   SELECT u.nom, u.prenom, COUNT(r.id) as total_rdv
   FROM rendez_vous r
   JOIN users u ON r.prestataire_id = u.id
   GROUP BY r.prestataire_id
   ORDER BY total_rdv DESC
   LIMIT 4

Classement :
   1ère place → Coiffeur avec le PLUS de RDV (exemple : 45 RDV)
   2ème place → Deuxième plus de RDV (exemple : 38 RDV)
   3ème place → Troisième plus de RDV (exemple : 32 RDV)
   4ème place → Quatrième plus de RDV (exemple : 28 RDV)

Utilité du classement :
   • Identifier les meilleurs prestataires
   • Encourager la performance
   • Justifier les récompenses/bonus
   • Analyser la satisfaction client
   • Évaluer la fiabilité des coiffeurs

SYSTÈME DE CLASSEMENT
─────────────────────────────────────────────────────────────────────────────

Critère : NOMBRE DE DEMANDES PAR SERVICE

Requête SQL :
   SELECT p.nom_service, COUNT(r.id) as nb_demandes
   FROM rendez_vous r
   JOIN services p ON r.service_id = p.id_service
   GROUP BY r.service_id
   ORDER BY nb_demandes DESC
   LIMIT 4

Résultat type :
   1. Coupe classique ........... 150 demandes (35%)
   2. Lissage ................... 95 demandes (22%)
   3. Teinte .................... 80 demandes (18%)
   4. Traitement profond ........ 70 demandes (16%)

Utilité du classement :

                        KKIAPAY — INTÉGRATION PAIEMENTS
================================================================================

QU'EST-CE QUE KKIAPAY?
─────────────────────────────────────────────────────────────────────────────
   • Plateforme de paiement mobile (Bénin, Afrique)
   • Traite les paiements avant les rendez-vous
   • Sécurisé et rapide
   • Intégration via API webhook

ACTIONS EN CAS D'ERREUR KKIAPAY
─────────────────────────────────────────────────────────────────────────────

Scénario 1 : PAIEMENT ÉCHOUE IMMÉDIATEMENT
   Status : PAYMENT_FAILED
   Action :
      1. Notifier client : "Paiement échoué"
      2. Proposer 2 nouvelles tentatives
      3. Si 3ème tentative échoue → Rembourser automatiquement
      4. Contact support : "Problème de carte ?"
   
Scénario 2 : TIMEOUT (Pas de réponse)
   Status : PENDING >5 minutes
   Action :
      1. Relance WhatsApp client : "Confirmez votre paiement"
      2. +10 minutes → Annuler RDV
      3. +10 minutes → Rembourser client
      4. Enregistrer comme tentative échouée

Scénario 3 : PAIEMENT RÉUSSI MAIS COIFFEUR NE RÉPOND PAS
   Status : SUCCESS (mais RDV = 'en_attente')
   Action :
      1. Relancer coiffeur par WhatsApp
      2. +30 minutes → Pas de réponse?
      3. Rembourser client automatiquement
      4. Notification : "Coiffeur n'a pas répondu"

Scénario 4 : CLIENT ANNULE APRÈS PAIEMENT
   Status : REFUND_REQUESTED
   Action :
      1. Retirer du solde coiffeur
      2. Rembourser client dans 24 heures
      3. Enregistrer dans transactions_portefeuille
      4. Notifier les deux parties

Code implémenté dans :
   → security/SecurePaymentOrchestrator.php
   → Gestion API webhooks KkiaPay

Fonctionnement : ✓ ACTIF (service externe)
