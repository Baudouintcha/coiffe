## 🔄 Changements détaillés

### 1. GÉOMÉTRIE

**De** :
```
Orbe doré avec halo + étoile ✨
→ Ressemble à : Un objet magique, une illusion
→ Sensation : "Wow, c'est de la tech!"
```

**À** :
```
Cercle pur avec point lumineux
→ Ressemble à : Une fenêtre vers une présence
→ Sensation : "Je parle à quelqu'un"
```

**Justification** : Le cercle est universel (nature, soleil, lune). Pas menaçant. Accueillant.

---

### 2. COULEURS

| Aspect | v3.0 | v4.0 | Raison |
|--------|------|------|--------|
| **Primaire** | Or (#D4AF37) | Bleu glacier (#4FA8D5) | Or = bling. Bleu = calme, naturel, confiance |
| **Psychologie** | Luxe distant | Bienveillance proche | Chat doit être accessible, pas intimidant |
| **Associations** | Bijou, premium froid | Ciel, eau, humanité | Naturel > artificiel |

---

### 3. TYPOGRAPHIE

#### Avant (v3.0)
- Sans-serif géométrique partout
- "Frappant à l'oeil" = "distrayant"
- Même polices pour tout
- Effet : Corporate, froid

#### Après (v4.0)

| Utilisation | Police | Poids | Raison |
|-------------|--------|-------|--------|
| **Interface** | Inter | 400-600 | Amicale, accessible, modern |
| **Messages IA** | Lora | 400-600 | Humanise, crée intimité |
| **Titres** | Playfair Display | 400-600 | Élégant, pas robotique |

**Justifications** :

1. **Inter** (sans-serif)
   - Arrondis naturels (pas géométrique)
   - Conçu spécialement pour interfaces numériques
   - Amical sans être infantile
   - Très lisible, distinctions claires (i/l/1)

2. **Lora** (serif pour IA)
   - Les serifs créent une "respiration" entre lettres
   - Rappelle une lettre écrite = humanité
   - Psychologiquement : "quelqu'un m'écrit"
   - Meilleure lisibilité sur longs textes

3. **Playfair Display** (titre)
   - Élégance sans froideur
   - Classique = humain, pas geek
   - Crée distinction : "Je suis une vraie personne"

---

### 4. ANIMATIONS

| État | v3.0 | v4.0 | Timing |
|------|------|------|--------|
| **Inactif** | Pulsation dorée | Respiration bleue | 2.8s (respiration humaine) |
| **Écoute** | Animation rapide | Pulse doux | 0.6s |
| **Réflexion** | Rotation rapide | Rotation lente | 1.8s |

**Principe** : Animations qui respectent le rythme humain, pas tech froid.
