✅ 7 SOLUTIONS POSSIBLES

1️⃣  MASQUER LES NUMÉROS (Virtual Numbers)
   ├─ Client voit : 01600001 (numéro virtuel)
   ├─ Appel automatique redirigé vers coiffeur (anonyme)
   ├─ Valable 2-3 jours seulement
   ├─ Coût : Twilio €50-100/mois (ou gratuit Vonage)
   └─ Impact : ⭐⭐⭐⭐ (Très efficace)

2️⃣  MESSAGERIE INTERNE OBLIGATOIRE
   ├─ Toute communication via la plateforme
   ├─ Chat intégré, pas de téléphone
   ├─ Plateforme trace 100% des messages
   └─ Impact : ⭐⭐ (Clients préfèrent tel)

3️⃣  COMMISSION INVISIBLE (Price Markup)
   ├─ RDV via plateforme : 6000 F
   ├─ RDV contact direct : 7500 F (+25%)
   ├─ Incitatif économique
   └─ Impact : ⭐⭐⭐ (Dépend des clients)

4️⃣  RÉVÉLATION PROGRESSIVE
   ├─ Numéro masqué par défaut
   ├─ Visible APRÈS 1er RDV complété
   ├─ Force min. 1 RDV via plateforme
   └─ Impact : ⭐⭐⭐⭐ (Simple + efficace)

5️⃣  LOYALTY POINTS (Récompense)
   ├─ Chaque RDV : +10 points
   ├─ Points = Remises futures
   ├─ Accumulation crée habitude
   └─ Impact : ⭐⭐⭐ (Psychologique puissant)

6️⃣  CONTRAT/CONDITIONS LÉGALES
   ├─ Accepter conditions = Contact via plateforme
   ├─ Contournement = Suspension 30j
   ├─ Couverture légale
   └─ Impact : ⭐ (Pas d'application technique)

7️⃣  ESCROW / PAIEMENT BLOQUÉ
   ├─ Argent client bloqué jusqu'à fin RDV
   ├─ Libéré APRÈS validation plateforme
   ├─ Coiffeur n'est payé que si RDV via plateforme
   └─ Impact : ⭐⭐⭐⭐⭐ (Force le respect)

🔧 CODE À AJOUTER (Étape 1 : Révélation Progressive)

// 1. Migration BD
ALTER TABLE rendez_vous ADD COLUMN phone_revealed_at DATETIME;
ALTER TABLE users ADD COLUMN nb_rdv_completed INT DEFAULT 0;

// 2. Fonction pour masquer
function shouldShowPhone($user_id) {
    $stmt = $pdo->prepare("
        SELECT COUNT(*) as completed
        FROM rendez_vous
        WHERE (client_id = ? OR prestataire_id = ?)
        AND statut_rdv = 'termine'
    ");
    $stmt->execute([$user_id, $user_id]);
    $result = $stmt->fetch();
    return $result['completed'] >= 1;
}

// 3. Affichage RDV
<?php
if (shouldShowPhone($current_user_id)) {
    echo "Coiffeur : " . $coiffeur['telephone'];
} else {
    echo "Coiffeur : " . substr($coiffeur['telephone'], 0, 3) . "****";
    echo " (Visible après 1er RDV)";
    echo " <a href='/messagerie'>👉 Contactez ici</a>";
}
?>

⚠️  PIÈGES À ÉVITER

❌ Ne pas masquer complètement les numéros
   → Les clients veulent une option "contact direct"
   → Faire progressif, pas radical

❌ Ne pas exiger trop de RDV avant révélation
   → Max 1-2 RDV avant révélation
   → Au-delà = frustration

❌ Ne pas ignorer messaging
   → Offrir chat intégré en même temps
   → Alternative au téléphone

❌ Ne pas négliger UX
   → Message clairs : "Pourquoi masqué ?"
   → CTA visible : "Contactez ici"
